# Hi, I'm Alyaz Cabbarova 👋

### Data Analyst · Excel · Python · Power BI

I turn raw business data into decisions: **clean it, model it, measure it, and tell the story** with dashboards. I also look for problems in the data that are easy to miss. In my retail project, for example, I found that the "plan" was an exact copy of sales lagged by 29 days, so "plan achievement" was really month-over-month change.

## 📌 How I work

- **Start from the business question**, then the data, never the reverse.
- **Check the data before trusting it:** duplicates, joins, date logic, how a "plan" was built.
- **Document everything:** every project has a README with findings, recommendations and limitations, plus DAX and data dictionaries.
- **Keep models reproducible:** Power BI projects are stored as text (PBIP/TMDL) in Git.
